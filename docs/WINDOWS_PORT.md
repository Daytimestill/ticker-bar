# Windows 移植说明

写给想把 TickerBar 移植到 Windows 的人。

我自己没有 Windows 机器，短期不会做这件事。这份文档不替你做决定，只把**难在哪、要做什么、有哪些坑**讲清楚，让你能在动手前判断值不值得。

下面所有平台断言都来自实际读依赖源码或官方文档，核实方式附在旁边，你可以自己复核。

---

## 一句话结论

**代码层面移植不难，难的是产品形态得重新设计。**

绝大部分代码是平台无关的——行情解析、交易时段判定、持仓收益、提醒穿越语义，一行都不用改。真正的问题只有一个，但它正好戳在这个产品的立身之本上。

## 核心难点：Windows 托盘不显示文字

这个应用的全部价值在于「不用打开任何窗口，扫一眼菜单栏就知道现在多少钱」。macOS 允许给托盘项设置文字标题，Windows 不允许。

`tray-icon` crate 源码里写得很直接：

```
/// ## Platform-specific:
/// - **Windows:** Unsupported
pub fn set_title<S: AsRef<str>>(&self, title: Option<S>)
```

> 复核：`cargo tree -p tray-icon` 查到版本，读 `~/.cargo/registry/src/*/tray-icon-*/src/lib.rs`

Windows 通知区域的规格就是一个图标位（100% 缩放下 16×16，高 DPI 下 24/32），外加悬停时的 tooltip。没有任何 API 能在旁边放一行字。

所以 `src-tauri/src/runtime/tray.rs` 里这句在 Windows 上是空操作，编译能过、运行无效：

```rust
tray.set_title(Some(&title))
```

**这不是能绕过去的实现细节，是平台能力的边界。** 你必须先决定 Windows 版用什么形态承载「一眼看到价格」，再谈写代码。

## 三个方向

### 方向一：把文字画进图标

每次刷新时把数值渲染成位图，用 `set_icon()` 替换。

- **能做到什么**：最接近 macOS 版的体验，不用额外窗口
- **代价**：图标位太小，实测只塞得下 4–5 个字符。显示 `+3.2%` 勉强可行，完整价格塞不下。必须自己处理 DPI 缩放，否则高分屏上一团糊
- **适合**：只关心涨跌幅、不需要看具体价格的人

### 方向二：图标 + 悬停提示

托盘只放一个随涨跌变色的图标，完整信息进 tooltip 和右键菜单。

- **能做到什么**：改动量最小。`set_tooltip()` 在 Windows 上是支持的，而且现有代码已经在用（`tray.rs` 的 `refresh_tooltip`），几乎不用新写
- **代价**：不悬停就只能看到红绿两色，等于把「扫一眼」降级成「停一下」。产品核心卖点损失最大
- **适合**：作为第一步跑通全流程，验证其余部分都正常

### 方向三：独立浮窗小组件

无边框、置顶、可拖动的小窗常驻桌面一角，托盘只保留右键菜单。

- **能做到什么**：信息量不再受限，甚至可以比 macOS 版显示得更多
- **代价**：工作量最大。位置记忆、多显示器、全屏应用时的避让、鼠标穿透，都要自己处理
- **适合**：愿意投入、想做出比原版更好的形态

**如果让我建议**：先按方向二把整条链路跑通——托盘、菜单、设置窗、通知、自启全部验证一遍，确认这些都没问题之后，再回头叠加方向一或三。反过来做的话，很可能在渲染上耗掉大量时间，最后才发现别的地方编译不过。

## 要做的事

除了上面的形态决策，剩下的都是明确的小改动。

### 必须改

| 位置 | 现状 | 要做什么 |
|------|------|---------|
| `tauri.conf.json` 的 `bundle.targets` | `["app", "dmg"]` | 改为 `["nsis"]` 或 `["msi"]`。`macOS` 段落原样保留，Tauri 会按平台各取所需 |
| `package.json` 构建脚本 | `pnpm release` 打 macOS universal 包 | 增加 Windows 构建命令，目标 `x86_64-pc-windows-msvc` |
| 设置窗口 | 靠 `LSUIElement` 不占 Dock | Windows 侧给窗口设 `skipTaskbar: true`，避免设置窗常驻任务栏 |
| 试发的 3 秒倒计时（`AlertSection.vue`） | 为了让用户切走窗口——macOS 不给前台 App 弹横幅 | **Windows 没有这个限制**，前台照弹。倒计时和相关文案应当删掉，否则是在解释一个不存在的问题 |

### 需要实测确认（代码可能不用改）

| 位置 | 情况 |
|------|------|
| 配置目录 | `app_config_dir()` 由 Tauri 按平台解析，Windows 落在 `%APPDATA%\<identifier>\`，**代码不用动**。但要实测确认目录真的建出来了 |
| 开机自启 | `tauri-plugin-autostart` 自带 `#[cfg(windows)]` 分支走注册表 Run 键，理论上直接可用。**装包后重启机器实测**，别只看代码 |
| 提醒通知 | Windows 走 WinRT Toast。**前提是应用有开始菜单快捷方式和 AppUserModelID**，绿色免安装版收不到通知。必须用 NSIS/MSI 安装包验证，`cargo run` 测不出来 |

### 一个必须如实交代的安全差异

`src-tauri/src/storage.rs` 把配置文件权限设为 `0600`，但那段代码被 `#[cfg(unix)]` 包着：

```rust
#[cfg(unix)]
{
    use std::os::unix::fs::PermissionsExt;
    // ...set_permissions(fs::Permissions::from_mode(0o600))
}
```

**Windows 上这段不执行，持仓数量与成本是明文躺在 `%APPDATA%` 里、没有任何权限收紧的。**

要么用 ACL 补上（`icacls` 或 `windows-acl` crate），要么在 Windows 版 README 里如实写明。**不要不处理也不说。**

## 不要动的部分

这些是纯业务逻辑，和操作系统无关，改了就是在制造回归：

- `src-tauri/src/domain/`、`portfolio.rs`、`alerts.rs` —— 交易时段判定、持仓收益、提醒穿越语义
- `provider.rs` —— 腾讯行情接口的请求与解析
- `config.rs` 的 schema 与版本迁移 —— **配置格式要与 macOS 版保持一致**，同一个人可能两台机器都在用
- 金额计算里的 `rust_decimal` —— 不要为了省事换成 `f64`，那会引入浮点误差
- 多币种合计**不跨币种相加** —— 这是刻意设计（没有汇率数据源），不是遗漏
- 现有的 62 条 Rust 测试与 88 条前端测试 —— 平台相关的用 `cfg` 隔离，不要删

同样不要删 macOS 分支。这个仓库要同时维护两个平台。

## 验收清单

代码写完不等于做完：

- [ ] `cargo clippy --all-targets -- -D warnings` 在 Windows 上干净
- [ ] `cargo test` 与 `pnpm vitest run` 全绿
- [ ] 托盘图标出现在通知区域，数值随行情刷新变化
- [ ] 右键菜单能列出全部股票、切换置顶、显示多币种合计
- [ ] 设置窗能开能关，关掉后进程仍在后台运行
- [ ] 提醒触发时弹出 Windows Toast（**用安装包测**）
- [ ] 「登录时启动」重启机器后真的生效
- [ ] 配置文件落在 `%APPDATA%`，删掉后能重建默认配置
- [ ] 断网后能恢复、休眠唤醒后能恢复
- [ ] 高 DPI 缩放（125% / 150% / 200%）下托盘和设置窗都不糊

## 一个已经踩过的坑

`.gitignore` 里排除 macOS Finder 图标缓存的那条规则，**不能写成 `Icon?`**——`?` 是 gitignore 通配符，会把 `src-tauri/icons/icon.png` 一起吞掉，而那是构建必需的资源。本地文件还在，只有克隆出去才炸。现在写的是 `Icon[$'\r']`，精确匹配那个以回车结尾的文件名。
