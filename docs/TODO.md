# 待办清单

## 稳定性验证

这是 Beta 转正式版唯一还没过的关卡，靠时间不靠写代码。

- [ ] 连续运行 5 个交易日：无崩溃、无菜单栏消失、无明显资源泄漏
- [ ] 睡眠唤醒后能自动恢复行情
- [ ] 断网重连后无需重启即可恢复
- [ ] 跨交易日切换（收盘 → 次日开盘）状态正确
- [ ] 提醒规则在真实行情下的触发准确性（并入上面的连续运行一起观察）
- [ ] 观察腾讯免费接口的稳定性与限制，必要时增加备用数据源

## 已知限制

不是待办，是做不到或不打算做的，如实记录：

- **通知横幅上会显示应用名「TickerBar」**，由 macOS 强制附加，无法按条隐藏。想更彻底伪装只能在打包时改应用显示名
- **应用未经 Apple 公证**，别人下载后需手动放行一次，方法见 README
- **多币种不换算、不相加**。没有汇率数据源，港币与人民币混加只会得出看似精确的错误数字，因此按币种分组显示

## 已决定不做

- **Apple Developer ID 签名 + notarization（$99/年）** —— 不值得为个人小工具付费。代价是别人首次打开需手动放行，且无法使用 Tauri 的自动更新（updater 依赖签名密钥）
- **刷新频率设置** —— 固定 3 秒，不暴露设置项
- **扩展时段** —— A 股与港股没有散户可用的扩展时段，开关永远不会生效，已连同配置字段一并移除
- **券商账户登录、自动读取持仓或交易**
- **投资组合管理**（调仓记录、跨股票组合分析）
- **移动端**

Windows 版不在本项目计划内，但整理了一份移植说明供他人参考：[`WINDOWS_PORT.md`](WINDOWS_PORT.md)。

## 完成定义

同时满足才从 Beta 标记为正式版：

1. 稳定性验证全部通过
2. 自动化测试与静态检查全绿
3. 已知限制在应用或文档中写明，不保留看似可用但实际无效的开关
